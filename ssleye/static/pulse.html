    No downstream task yet

    Downstream performance = how good the frozen encoder is for a real labelled task, checked every few thousand steps. It is optional: every other page works without labels. Add a task in the training script:

    run.add_downstream("cifar10-cls", task="classification",
                   train=(x_train, y_train), test=(x_test, y_test),
                   every=1000, class_names=names)

    Classification is supported now (kNN, linear probe, few-shot). Segmentation and detection need a labelled dense dataset such as Pascal VOC and are planned.
